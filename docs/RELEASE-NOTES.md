# v0.1.0-alpha.2

Experimental opt-in sequential continuity between Codex and Claude Code. Existing OpenCode/OpenRouter configurations retain their original route.

- Explicit ordered destinations and models, subscription authentication checks, official availability signals, and separate subscription/API accounting.
- Concrete Smart tool approvals with restricted native adapters; unsupported versions or effective policies block execution.
- Private atomic handoffs, project fingerprints, preserved task counters, and explicit cross-process continuation. Pending or uncertain effects require inspection and are never replayed automatically.
- Backend diagnostics, subscription configuration templates, sanitized coordination output, and opt-in isolated continuity/lifecycle pilots.
- Reproducible reliability evaluation and local provider fault injection from the previous source-only update.

Validation includes 307 automated tests, 15 scoped permission checks, simulated continuity in both directions, native policy smokes, and independent package installation. Authorized isolated real pilots exercised both backends, both handoff directions, cross-process recovery, cancellation, and denied approvals. These checks do not establish broad repository reliability, actual quota-exhaustion behavior, cost savings, or model-quality equivalence. Native adapters are pinned to the versions documented in CONTINUITY.md; newer versions require verification.

Private pilot reports, prompts, native session identifiers, and credentials are excluded from the release. No additional real inference is required to package this alpha. The GitHub prerelease includes an npm-compatible .tgz and SHA-256 checksum; npm registry publishing remains disabled.

# v0.1.0-alpha.1

First public experimental alpha of Smart Router CLI.

- Explainable deterministic routing across Fast, Balanced, and Deep.
- Native OpenCode session continuity, staged permissions, manual overrides, checkpoints, cancellation, and explicit continuation.
- Executed validation evidence, bounded repair/escalation, structured review, and separate handling of local limits.
- Local scripted native smokes and a reproducible 20-case synthetic benchmark runner.
- English CLI and documentation; English/Spanish task classification.

Local checks and GitHub CI cover Node 22/24 on Linux and native smoke workflows on macOS with Node 24. CI evidence applies to the release commit; Windows is not validated. Tests with a scripted provider do not establish real-model quality.

Historical experiments predate this public commit. They contain incorrect implementations, permission failures, infrastructure interruptions, and budget cuts. They do not establish cost savings at comparable quality.

The general CLI budget is checked between requests, not a hard provider invoice cap. Native history can contain source code and prompts; approval is not an OS sandbox. Treat this alpha as an experiment in a disposable checkout.

The GitHub prerelease provides an npm-compatible local-install .tgz and a SHA-256 checksum. npm registry publishing is disabled.
