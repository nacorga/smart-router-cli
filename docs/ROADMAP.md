# Alpha roadmap

1. **External reproducibility.** Collect sanitized reproductions from users who finish tasks in their own repositories. Track setup failures, platform issues, and completion evidence rather than stars.
2. **Validation and budget robustness.** Improve command adherence, local-limit reporting, interrupted-session inspection, and conservative cost controls without weakening permissions or inventing evidence.
3. **Quality/cost evaluation.** Add varied real tasks and independent criteria; report tests, implementation quality, workflow completion, review conformity, and all spend separately. Savings with comparable quality remain unproven.

No hosted service, npm registry release, new TUI, or multi-agent orchestration is promised for this alpha.

## Experimental continuity work

Sequential destination routing, private handoff checkpoints, and simulated native contracts are implemented behind an opt-in version 2 configuration. Claude uses a closed Smart tool bridge; both installed native tool profiles have local scripted-provider checks. Codex uses a restricted dynamic-tool profile verified with the installed native binary and a local scripted provider. Bidirectional subprocess handoffs pass the reliability harness with independent validation. Authorized real fixture pilots passed for each backend, both handoff directions, explicit cross-process continuation, validation-child cancellation, and permission denial. Actual quota exhaustion, general hard-crash recovery and broader real tasks remain unvalidated. Parallel workers and distributed orchestration are outside this delivery.
